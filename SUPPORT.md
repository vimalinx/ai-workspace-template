# Support

Use discussions or a question issue for setup and workflow questions. Use a bug issue for reproducible defects and private security reporting for vulnerabilities.

Supported baseline:

- Python 3.11–3.14;
- Git 2.x;
- Linux and macOS POSIX environments;
- UTF-8 workspaces.

Windows is not currently supported. External `cron`, `systemd`, CI, editors, and AI runtimes are integrations rather than assumed dependencies. Community support is best effort; the Apache-2.0 license provides no warranty.
