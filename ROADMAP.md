# Roadmap

## Autonomous protocol alpha

- Validate cross-session handoff between at least two unrelated coding Agents.
- Run a real project for 24 hours with agenda generation, search-tree expansion, experiments, independent evaluation and recovery after process restart.
- Add migration fixtures from 0.1.x governed workspaces to 0.2.x autonomous control planes.

## Public alpha

- Publish the privacy-reviewed GitHub template with Apache-2.0 licensing.
- Validate clean bootstrap, adoption, activation, audit, and rollback without private host dependencies.
- Collect issues from at least three unrelated workspace domains.

## Public beta

- Add upgrade/migration fixtures across released schema versions.
- Publish sanitized end-to-end case studies and release archives with checksums.
- Validate additional POSIX shells and document remaining platform differences.

## Stable

- Stabilize configuration and receipt contracts based on external adoption evidence.
- Define a long-term support and deprecation window.
- Decide, from user demand, whether a packaged CLI or runtime plugin should complement the GitHub template.
